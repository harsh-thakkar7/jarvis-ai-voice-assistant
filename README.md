# JARVIS AI Voice Assistant

An AI voice assistant inspired by Tony Stark's JARVIS, featuring:
- Voice recognition and text-to-speech
- GUI with arc reactor animation
- Multiple AI model support (Groq, Gemini)
- Web search with citations
- Weather, timer, unit conversion
- App launching and website opening

## Requirements
```bash
pip install -r requirements.txt
```

## How to Run
```bash
python main.py
```

## Features
- Voice commands
- Text input
- Real-time animations
- Multiple AI backends
